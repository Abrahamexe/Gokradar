# Güvenlik Politikası

## Açık bildirme

Bir güvenlik açığı bulduysanız lütfen herkese açık issue **açmayın**. Bunun yerine GitHub'ın
özel bildirim özelliğini kullanın: depo sayfasında **Security → Report a vulnerability**.

Bildirimde şunlar yardımcı olur:

- Etkilenen dosya veya endpoint
- Açığı yeniden üretme adımları
- Olası etkisi

Bildirimler en kısa sürede incelenir ve sonuç size bildirilir.

## Kapsam

Bu depodaki kaynak kod (`src/`, `config.py`, `tools/`). Üçüncü taraf servisler (adsb.lol, OpenSky,
Stadia Maps, Planespotters.net vb.) ve kütüphaneler kendi güvenlik süreçlerine tabidir.
